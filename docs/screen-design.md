## 2. 画面遷移図

問題集一覧画面(トップ)
 ├─ 「新規作成」→ 問題集作成・編集画面
 ├─ 問題集を選択 → 問題集詳細画面
 ├─ 削除(確認ダイアログを表示)
 └─ 「履歴を見る」→ 学習履歴画面

問題集作成・編集画面
 ├─ 保存 → 問題集詳細画面(新規作成時)/ 問題集詳細画面(編集時)
 └─ キャンセル → 元の画面に戻る

問題集詳細画面
 ├─ 「問題集名を編集」→ 問題集作成・編集画面(編集モード)
 ├─ 「問題を追加」→ 問題作成・編集画面
 ├─ 既存の問題を選択(編集)→ 問題作成・編集画面
 ├─ 問題を削除(確認ダイアログを表示)
 ├─ 「クイズ開始」→ クイズ出題画面
 └─ 戻る → 問題集一覧画面

問題作成・編集画面
 ├─ 保存 → 問題集詳細画面へ戻る
 └─ キャンセル → 問題集詳細画面へ戻る

クイズ出題画面
 ├─ 選択肢をクリック → 正誤表示(1〜2秒)→ 自動で次の問題へ
 └─ 全問終了 → 結果画面

結果画面
 ├─ 「同じ問題集をもう一度」→ クイズ出題画面(全問)
 ├─ 「間違えた問題だけ再挑戦」→ クイズ出題画面(間違えた問題のみ)
 └─ 「問題集一覧に戻る」→ 問題集一覧画面

学習履歴画面
 └─ 戻る → 問題集一覧画面

## 3. 各画面の詳細

### 3.1 問題集一覧画面
- 表示項目: 問題集名、問題数、直近の正答率
- 操作: 新規作成、選択(詳細画面へ)、削除(確認ダイアログあり)、「履歴を見る」ボタン

### 3.2 問題集作成・編集画面
- 入力項目: 問題集名
- 操作: 保存、キャンセル

### 3.3 問題集詳細画面
- 表示項目: 問題集名、問題一覧(問題文)
- 操作: 問題集名の編集、問題の新規作成・編集・削除(確認ダイアログあり)、クイズ開始ボタン

### 3.4 問題作成・編集画面
- 入力項目: 問題文、選択肢1〜4、正解(選択肢のうちどれが正解か)
- 操作: 保存、キャンセル

### 3.5 クイズ出題画面
- 表示項目: 問題文、選択肢4つ、進捗(第n問 / 全問数)
- 操作: 選択肢をクリックして回答 → 正誤を即座に表示(1〜2秒)→ 自動で次の問題へ
- 間違えた問題はセッション内で再出題する

### 3.6 結果画面
- 表示項目: 正解数 / 全問数、正答率
- 操作: 「同じ問題集をもう一度」「間違えた問題だけ再挑戦」「問題集一覧に戻る」

### 3.7 学習履歴画面
- 表示項目:
  - セッション単位の履歴一覧(日時、問題集名、正解数 / 全問数)
  - 問題集ごとの累積正答率一覧
- 操作: 戻る
