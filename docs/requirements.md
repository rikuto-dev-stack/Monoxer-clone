# 要件定義書

## 1. プロジェクト概要
Monoxerを参考にした、クイズ作成・出題型のWebアプリケーション。
学習目的(ポートフォリオ)で個人開発する。

## 2. 目的
- Web開発(フロントエンド・バックエンド・DB・将来的にはAWSデプロイまで)を
  一通り自分の手で経験し、技術力を身につける
- 完成後は自分自身が実際に使えるクイズ・暗記ツールとする

## 3. 想定ユーザー
- 開発者本人のみ(個人利用)
- MVPではログイン機能なし・単一ユーザー前提
- 将来ポートフォリオとして他人に見せる可能性は考慮しておく

## 4. 機能要件(MVPスコープ)

| # | 機能 | 内容 |
|---|------|------|
| 4.1 | 問題集管理 | 問題集(デッキ)単位でクイズをグループ化。作成・編集・削除・一覧表示(フルCRUD) |
| 4.2 | 問題管理 | 各問題集の中に、四択問題(問題文・選択肢4つ・正解)を作成・編集・削除・一覧表示(フルCRUD)。解説文・画像は今回は含めない |
| 4.3 | クイズ出題 | 問題集を選んで出題開始。ランダム順で出題し、間違えた問題はそのセッション内で再出題する。MVPでは問題集の全問を毎回出題する。クイズ終了後、結果画面から「同じ問題集をもう一度」または「今回間違えた問題だけを再挑戦」を選択できる |
| 4.4 | 正誤判定 | 選択した答えが正解かをその場で判定・表示 |
| 4.5 | 学習履歴 | 「いつ・どの問題を・正解したか不正解だったか」を記録。問題集ごとの正答率などを簡単に表示 |

## 5. 非機能要件
- 対応デバイス:PC・スマートフォン両方(レスポンシブデザイン)
- 将来的にAWSへデプロイし公開する想定。可能な限り無料枠(Free Tier)内で
  運用したいという制約がある
  → 今後、構成案を提示する際は、無料枠を超えるリスクのある
    サービス・使い方は都度警告する
- MVP時点では認証機能がなく、公開情報を扱わない前提のため、セキュリティ
  要件は最小限(SQLインジェクション対策など基本的な部分のみ)。ただし
  初期段階からセキュリティを意識する方針のため、設計時にも触れる

## 6. スコープ外(将来拡張の候補)
- 出題数を指定できる機能(例:10問だけ出題する等)※MVPは全問出題、
  安定後にこの機能へ拡張する
- 間隔反復学習(忘却曲線に基づく優先出題)
- ログイン・複数ユーザー対応
- 解説文・画像の添付
- 四択以外の出題形式(記述式、○×問題など)
